# Droid Desserts App

Sebuah proyek aplikasi Android sederhana untuk mendemonstrasikan penggunaan RecyclerView di dalam arsitektur CoordinatorLayout.

📱 Tentang Proyek

Aplikasi ini adalah contoh dasar bagaimana cara mengimplementasikan dan menampilkan daftar (list) data hidangan penutup (dessert) secara efisien di Android. Tata letak utama didefinisikan menggunakan CoordinatorLayout dan LinearLayout untuk mendukung header teks yang rapi di atas daftar.

✨ Fitur

- Menampilkan daftar item hidangan penutup menggunakan RecyclerView.
- Menggunakan CoordinatorLayout untuk tata letak utama yang responsif.
- Header teks kustom ("Droid Desserts") yang menyatu dengan tata letak daftar.

🛠️ Teknologi yang Digunakan

- Bahasa: Kotlin
- UI Layout: XML (CoordinatorLayout, LinearLayout, RecyclerView)
- IDE: Android Studio

🚀 Cara Menjalankan Proyek

1. Clone repository ini ke komputer lokal Anda:
   ```bash
   git clone [https://github.com/anggraenisilvi413-sudo/DessertRecycleView.git](https://github.com/anggraenisilvi413-sudo/DessertRecycleView.git)
Buka Android Studio.

Pilih Open an existing project dan arahkan ke folder hasil clone.

Tunggu proses Gradle sync selesai.

Jalankan aplikasi di Emulator atau perangkat Android fisik Anda dengan menekan tombol Run (Shift + F10).
